# Codebook: Indigenous Representation in the Bolivian Plurinational Legislative Assembly (2010–2020)

**Dataset:** ALP_2010_2015.csv and ALP_2015_2020.csv

## Variable definitions

| Variable | Description |
|---|---|
| NOMBRE | Nombre del legislador |
| CAMARA | Cámara legislativa |
| DEPARTAMENTO | Departamento del representante |
| PARTIDO | Partido Político |
| ORG_SOC | Organización social |
| PROFESION | Profesión u ocupación |
| INDIGENA | Identificación indígena (1 = Sí; 0 = No) |
| GENERO | Género |
| NACIMIENTO | Lugar de nacimiento |
| CIRCUNS | Tipo de circunscripción |
| ETNICIDAD | Identificación étnica específica |
